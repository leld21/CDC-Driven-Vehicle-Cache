## Level 3 — Components (worker)

```mermaid
C4Component
    title Component Diagram - .NET 10 Worker

    ContainerQueue(kafkaVehicles, "Kafka: vehicles topic", "op r/c/u/d")
    ContainerQueue(kafkaPositions, "Kafka: positions topic", "op r/c")
    ContainerDb(valkey, "Valkey", "hash per vehicle")

    Container_Boundary(worker, ".NET 10 Worker") {
        Component(vehicleConsumer, "Vehicle Topic Consumer", "BackgroundService + Confluent.Kafka", "Consumes vehicles CDC; manual offset commit")
        Component(positionConsumer, "Position Topic Consumer", "BackgroundService + Confluent.Kafka", "Consumes positions CDC; manual offset commit")
        Component(projector, "Per-Vehicle Projector", "Domain logic", "Deserializes envelope; maps to a partial field-group update (state or position)")
        Component(orderingGuard, "Ordering + Idempotency Guard", "Domain logic", "Resolves ordering key (LSN vehicles / recordedAt positions); coalesces null LSN to 0 (ADR-001/007). Enforcement runs in the Lua below.")
        Component(cacheWriter, "Cache Writer", "StackExchange.Redis + Lua", "Atomic compare-and-set HSET per field group; this is where ordering + idempotency are enforced (ADR-002/006)")
    }

    Rel_D(kafkaVehicles, vehicleConsumer, "CDC envelope")
    Rel_D(kafkaPositions, positionConsumer, "CDC envelope")
    Rel_D(vehicleConsumer, projector, "Raw envelope")
    Rel_D(positionConsumer, projector, "Raw envelope")
    Rel_D(projector, orderingGuard, "Field-group update + ordering value")
    Rel_D(orderingGuard, cacheWriter, "Write request (values + watermark)")
    Rel_D(cacheWriter, valkey, "EVAL: conditional HSET")
    Rel_Back(cacheWriter, vehicleConsumer, "Write confirmed -> commit offset")
    Rel_Back(cacheWriter, positionConsumer, "Write confirmed -> commit offset")

    UpdateLayoutConfig($c4ShapeInRow="2", $c4BoundaryInRow="1")
```

Notes:

- The per-vehicle **merge is emergent in the Valkey hash** via independent
  per-field-group partial writes (ADR-005); the worker performs no in-memory
  join and holds no cross-stream buffer.
- **Ordering + idempotency are enforced atomically inside the Lua script**
  (Cache Writer), not by a read-then-decide step in the worker, which would be
  racy. The Ordering Guard only resolves/normalizes the ordering value.
- Offsets are committed **after** the write is confirmed (ADR-002), so a crash
  mid-stream redelivers and safely re-applies as a no-op.
